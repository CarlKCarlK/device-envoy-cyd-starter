# Snake background asset

`snake-background-v2.tga` is the active uncompressed 24-bit 320×240 TGA. Its
editable high-resolution source is `snake-background-v2-source.png`. It
supplies only static decorative artwork. Snake, food, collision outline,
scores, control symbols, and modal UI are always program-rendered.

The v2 artwork was generated for this repository with OpenAI's image-generation
tool and has no external source asset. The original development placeholders
remain as `snake-background.tga` and `snake-background-source.png`.
